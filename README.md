# MoneySplit - Buddy Expense Tracker

MoneySplit is a modern, intuitive, and self-contained web application designed to simplify group expense tracking and debt settlement. Perfect for trips, room sharing, or group events, it provides real-time calculations and automated "Who Pays Whom" instructions.

## 🚀 Key Features

- **Buddy Management**: Easily add or remove group members.
- **Smart Record Keeping**: Input expenses with descriptions, amounts, and specific payers.
- **Automated Calculations**: 
    - Real-time display of total group spending.
    - Automatic calculation of per-head share.
    - Visual balance tracking (Positive for Credit, Negative for Debt).
- **Simplified Settlements**: A built-in algorithm that calculates the minimum number of transactions needed to clear all debts.
- **Professional Export**: Download a comprehensive PDF report containing your full transaction history and settlement instructions.
- **Branded Interface**: Clean, professional UI featuring Stockholding corporate styling.
- **Data Privacy**: Entirely client-side application; data remains in your browser and is never uploaded to any server.

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid)
- **Backend**: No database and no data gets stored
- **Scripting**: Vanilla JavaScript (ES6+)
- **Libraries**: 
    - [jsPDF](https://github.com/parallax/jsPDF) - For PDF generation.
    - [jsPDF-AutoTable](https://github.com/simonbengtsson/jsPDF-AutoTable) - For structured tables in reports.

## 📥 Installation & Usage

1. **Clone or Download**: Save the `index.html` (or `MoneySplit_v9_Final.html`) file to your computer.
2. **Open**: Double-click the file to open it in any modern web browser (Chrome, Edge, Safari, Firefox).
3. **Host (Optional)**: Since it is a static file, you can host it for free on **GitHub Pages**, **Netlify**, or any static site provider.

## 📋 How to Use

1. **Add Buddies**: Enter the names of all people involved in the group.
2. **Record Expenses**: Enter each bill, select who paid it, and click "Add Expense."
3. **Check Balances**: View the "Live Balances" card to see who is currently in credit or debit.
4. **Settle Up**: Refer to the "Settlement Plan" to see exactly who should pay whom.
5. **Download**: Click "Download PDF" to save a permanent record of the session.
